PlugShare data in Home Assistant.

Station and outlet data.

Each configured location creates one Home Assistant device with station details and sensors for every outlet returned by PlugShare.

01

Live occupancy

See available and occupied stall counts alongside the station's overall operating status.

02

Outlet details

Monitor status, rated power, voltage, current, and the last status-change timestamp for each plug.

03

Station details

View pricing, access rules, fast-charger capability, repair alerts, network details, and the latest API refresh time.

Install and configure.

No account credentials are required. Add a location ID and Home Assistant will poll the station data.

01 / ADD

Install with HACS

Add this repository as a custom integration, then download PlugShare.

02 / FIND

Copy the location ID

Use the number at the end of a PlugShare URL, such as 741158.

03 / CONNECT

Configure the integration

Open Settings, Devices & Services, and add PlugShare with that ID.
